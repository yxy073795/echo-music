# Echo Music

**你的音乐，另一种聆听方式。** · Your music. A different way to listen.

一款为本地音乐而生的 Windows 音乐播放器：本地扫描、AI 歌词翻译、AI DJ 无缝混音。免费、离线、无需账号。

## 亮点

- **本地音乐扫描**：自动扫描电脑里的 MP3，按专辑、歌手、流派整理成私人音乐图书馆，数据永远属于你
- **AI 歌词翻译**：歌词逐行滚动，DeepSeek AI 自动翻译成中文对照显示，听懂每一句
- **AI DJ 无缝混音**：节拍锁定、乐句对齐、调性匹配，歌曲在鼓点中自然相融，过渡无停顿
